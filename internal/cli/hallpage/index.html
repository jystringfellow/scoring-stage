Using stage

  1. Once per machinestage setup
  2. Start a stagestage up <repo> <slug>
  3. Run your agent or loop as a jobstage exec --detach <slug> -- <command>
  4. Answer an agent that waits for youstage attach <slug> <terminal>
  5. Ship what it madestage ship <slug>

Everything here is read from inside each stage, bounded and escaped. Nothing on this page can send input to an agent.

Read only: this page shows what each stage reports and never sends anything to a stage. Stop it with Ctrl-C in the terminal that ran stage hall.
